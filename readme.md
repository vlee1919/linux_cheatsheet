
Module 1: Git and Linux Cheatsheet

ls = list = Displays all files and folders within current directory.

cd = change directory = Moves your terminal from one folder to another

mkdir = make directory = Creates a brand new folder in your current location.

touch = Instantly creates a new, empty file

rm = remove = Deletes a file permanently

mv = move = Moves a file to a new location or renames it

cat = Reads the contents of a file and prints it directly into your terminal

pwd = print work directory = Shows the exact, full path of the folder you are currently located in


GIT Commands

git init - Sets up a brand new, empty Git repository in your current directory

git clone = Downloads an exact copy of an existing repository from a remote server (like GitHub) to your local machine.

git status = Shows you the current state of your project, including which files have been modified or are ready to be saved.
